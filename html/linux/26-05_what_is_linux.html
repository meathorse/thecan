What is Linux?

A normal person's guide to Linux

If you're somewhat tech-adjacent, perhaps, you've heard the name Linux in articles or via memes, or you've seen headlines stating that this is "The Year of Linux on the Desktop" - you've been hearing this for the past 10 years. While you have an idea that Linux is a free Operating System that super-nerds use to spite Bill Gates, you have little idea beyond that what Linux actually is and perhaps it's time to learn a little more.

tl;dr Linux (Wikipedia)

What is Linux?

Linux as a catch-all term, is a Free and Open Source (Wikipedia) Operating System that consists of the Linux Kernel, the GNU Project (Wikipedia) and dozens of other software applications bundled together to make a Distro. Because of the interdepenent relationship between the Linux Kernel and the GNU Tools, you might see it referred to as GNU/Linux in geekier circles.

Linux is a world-class operating system that has become the dominant Operating System (Wikipedia) - across mobile, servers as well as the sole choice for the top 500 super-computers worldwide. Only the desktop remains unconquered.

Linux is typically "Free" - both in the sense that:
  1. It doesn't cost you money to use it (although there are exceptions).
    2. and
  2. You're "Free" to do what you like with it - including copying, modifying and repackaging it into something new.

What is a Distro?

Above, I mentioned 'Distro' - this is what most people think of when we talk about Linux as a PC Operating System. A 'Distro' or 'Distibution' (Wikipedia) is a collection of software packages and tools packaged together with the GNU/Linux core to achieve a specific purpose. Often this will be a functional choice, sometimes technical or maybe even philosophical. A disto is what gives Linux its usable form.

Any linux Distro starts with the same core components:

  • Linux Kernel - the first half of the system core, the Kernel acts as a go-between the hardware and the software users
  • GNU Project - the second half of the system core, the GNU Project provides all the major system tools the user needs to perform vital operations

For a high-level description, a typical Disto will make choices of what packages to include for the user in regards to the major system components, including:

  • BootLoader - responsible for loading/starting the operating system once the hardware has been powered on (GRUB, systemd, LILO)
  • Display System - responsible for creating the images on the screen (X11, Wayland)
  • Package Manager - Controls software installation and system updates/upgrades (Apt, Pacman, DNF)

  • Desktop environment - the GUI (Graphical User Interface) that provides the menus, icons and things for you to click on. (KDE, Gnome, Cinnamon, MATE)
  • File Manager - how you create, find, open, copy or delete your files and folders/directories (Konqueror, Nautilus, Dolphin)
  • Common useful software - Productivity Suite (Libre Office), web browser (Firefox), email client (Thunderbird), image editor (Gimp), Video editor (DaVinci Resolve) and much more.

Put all these packages together and you have a Linux Distribution. An important distinction borrowed from Unix (Wikipedia) is the idea that a piece of software should be developed to do one thing, and do it well (Wikipedia). This is why Distros have so many different, excellent options to choose from for each function. Many Distos provide more than one version, swapping out major components - most notably the Desktop Environment - while keeping the remaining sofware the same. Anyone with enough know-how and determination could swap out any component in a Distro for another.

In the Windows world, Windows 11 Profesional and Windows 11 Home could be considered different 'Distros' of Windows 11 as there is a (small) difference in the installed software and functionality between the two.

The percieved downside of this endless choice and interchangablity is the enourmous number of Distros available - with the Linux family tree looking like a stand-in for Ghengis Khan's family tree. Each Distro can be modified and repackaged to become its own Distro but remains 'related' to the distro it was based on. The benfit of such variety is that you're sure to find something that fits your needs - be that a general purpose desktop, highly focused appliance for network or server workloads or even creating an arcade emulator.

You can simplify this massive list by focusing on the base/parent Distros - in particular, the big-three:

Debian

With a reputation for a stable and cautious approach, Debian may not support the latest and greatest software or hardware, but what it does provide is a stable base for any other Distro by using proven packages and upgrading slowly and deliberately. A very good choice for maximum reliablity and uptime, many beginner-friendly Distros are built on top of a Debian base.

Popular Debian-based Distros:

  • Linux Mint (Recommend)
  • Ubuntu
  • ZorinOS

Arch

Arch is the bleeding-edge of Linux. The latest and greatest packages are often available as soon as they're ready. Because these new packages are not battle-tested, any undiscovered bugs are more likely and may break the system. There are ways to mitigate some of these risks and many users operate successfully for years without issues. Using Arch was considered a badge of honor due to the difficulty of installation and the self-reliance required if the system did break but it has become more of a meme in recent years as many appear to use it for the 'street-cred'. The Arch Wiki (wiki.archlinux.org) is probably the most detailed Linux documentation avaialble, however due to the 'elite' perception of the Distro, you're more likely to encounter the toxic side of Linux and gate-keeping behaviour in the community (although it can be found anywhere!).

Arch is not recommended as a beginner distro unless you reveal in the challenge of, want to brag that you use Arch btw (knowyourmeme.com) or enjoy micromanaging your OS to monitor and account for potentially system-breaking updates.

Popular Arch-based Distros:

  • CachyOS (Recommend)
  • Arch
  • SteamOS

Red Hat/Fedora

Red Hat is traditionally best known as the standard 'Enterprise' Distribution, although it's upstream relative Fedora takes a more public-facing role as it provies a test-bed for new features before these reach the enterprise. Compared to Debian, Fedora is updated more regularly and with newer features - often leading the charge for adopting new technology before many other Distros but it a way that is still reliable. Fedora is (in my mind) the goldilocks Distro between being conservative and reliable while remaining modern and up-to-date.

Popular Red Hat-based Distros:

  • Fedora (Recommend)
  • Red Hat
  • Bazzite

Why is Linux receiving increased attention on the desktop?

Begining in 2025 with Windows 10 reaching end-of-support, there was a increase in the uptake of Linux on the desktop. This was amplified by the abitrary hardware restrictions applied by Windows 11 which meant perfectly acceptable hardware was unable to (officially) upgrade to Windows 11 and almost as if they wanted to double-down, Microsoft increased the hostility of Windows 11 towards users with greater push for AI features that few wanted and were often enabled by default.

This has led to increased exposure, articles and discussion - not that the Linux community needed more encouragement to talk about its favourite OS!
